# 점심 대화 (LunchActivity) Day 1-30 검수 문서

검수 기준:
1. 정답 경로(동료 → ✅ → reply → ✅)가 자연스럽게 흐르는가
2. 단어가 문맥에서 자연스럽게 등장하는가 (억지 X)
3. 오답 = 한국인 실전 실수 (콩글리시 / 과격식)
4. 동료 톤 = 프로페셔널 캐주얼 (한영 혼용·슬랭 최소)

표기: ✅ 정답 / ❌C 콩글리시 / ❌F 과격식 / → 교정 리액션
