# 유비챌 vs 1일1비 — 두 상품 포지셔닝

두 상품은 같은 우산(유버디) 아래에 있지만, **다른 자아의 사용자**한테 **다른 가치**를 준다.

## 핵심 비교표

| 축 | 유비챌 (5기 기준) | 1일1비 |
|---|---|---|
| 형태 | 4주 코호트 (사람이 운영) | 무제한 셀프서브 (자동화) |
| 결제 모델 | 기수당 일시불 (베이직/프리미엄) | 월·연 구독 |
| 학습 매개체 | 영작 인증 + AI 리뷰 + 발표 | 시나리오 롤플레잉 + NPC 응대 |
| 컨텐츠 핵심 | 비즈니스 영어 표현 (3개/일) | 회사 상황·문화·어휘 통합 |
| 사람/시스템 비중 | 운영자 + 동기 (커뮤니티 ↑) | NPC + 시스템 (혼자 모드) |
| 진도 | 모두 같음 (코호트 동기화) | 개인별 입사일 기준 |
| 게임화 | 빙고, 스트릭, 검증 통과 | 직급, 시나리오, 평가, 승진 |
| 강도 | 고강도 (영작 매일 + 발표) | 저~중강도 (출퇴근길 5-10분) |
| 기간 | 4주 한정 | 무제한 |

## "둘 다 고민하는 사람"한테 뭐 추천할까 — 결정 트리

### A 타입 → **유비챌**
- "혼자 하면 안 함, 사람이 챙겨줘야 함"
- "단기 4주 죽기살기로 끝내고 결과 갖고 싶음"
- "영어 발화·작문 연습이 진짜 필요함"
- "동기들이랑 같이 가는 게 동력이 됨"
- "수료증·증빙 같은 게 필요함"

### B 타입 → **1일1비**
- "꾸준히 자기 페이스로 하는 게 더 잘 맞음"
- "지금 당장 영어보다 회사 분위기·용어 자체가 어색함"
- "공부 같은 거 못 버틴다, 게임처럼 하고 싶음"
- "출퇴근 자투리 5-10분이 내 한계"
- "시간 자유롭게 쓰고 싶음"

### C 타입 → **둘 다, 순차적으로**
- 먼저 **1일1비로 회사 감각·기본 어휘 잡기** (저강도 진입)
- 어느 순간 "더 본격적으로 영어 한번 빡세게" 가고 싶을 때 **유비챌 한 기수 들어가기** (고강도 부스터)
- 끝나고 다시 1일1비로 일상 유지 (헬스장 PT 후 혼자 운동 가는 패턴)

## 시너지 funnel

- 1일1비 신규 → 90일 사용 → 더 깊이 가고 싶은 욕구 발생 → 유비챌 기수 모집 시 자동 우선 알림
- 유비챌 졸업생 → "끝났는데 감 잃기 싫음" 욕구 → 1일1비 졸업생 할인 입사

핵심: **유비챌은 점프, 1일1비는 일상.** 점프와 일상은 안 겹친다.

## 컨텐츠 중복 위험 관리

- **유비챌** = 미국식 비즈니스 영어 idiom·phrase 중심
- **1일1비** = 한국식 + 영어 혼합 비즈니스 어휘 + 상황·문화·관계 (보고체계, 부서 정치, 회의 룰)
- 어휘 카테고리부터 다르게 설계해서 중복 최소화
- 겹치는 단어가 있다면 1일1비에서는 "유비챌에서 본 그 표현, 이번엔 회의실에서 직접 써봅시다" 같은 식으로 의도된 복습으로 활용

## 가격대 (가설)

| 상품 | 객단가 | 빈도 | 연 LTV 추정 |
|---|---|---|---|
| 유비챌 베이직 | ?만원 (1회) | 1-2 기수/년 | 한 번 잡으면 끝 |
| 유비챌 프리미엄 | 더 높음 | 1-2 기수/년 | |
| 1일1비 월구독 | 1.5-3만원 | 매월 | 12-24만원 (이탈 안 시) |
| 1일1비 연구독 | 12-20만원 | 매년 | 12-20만원 |

→ **유비챌 = 한 번에 큰 금액 / 1일1비 = 작은 금액 누적.** 두 가지 가격 심리 다 잡힘.
