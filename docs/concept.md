# 1일1비 — 컨셉 정의서

> 1일 1비즈니스. 회사를 흉내 내며 비즈니스 어휘와 감각을 키우는 시뮬레이터 구독 서비스.

## 한 줄 정의
회사 시뮬레이터 + 비즈니스 어휘 학습 + 직급 RPG.

## 누구를 위한 서비스인가
- 사회 초년생 / 신입사원 / 이직 준비생
- 비즈니스 어휘·표현·문화에 약한 사람
- "공부"보다 "게임"이 맞는 사람 (혼자 묵묵히 영작 인증 같은 건 못 버티는 타입)
- 출퇴근길 5–10분, 자기 페이스로 하고 싶은 사람

## 핵심 메커니즘
1. **개인 입사일 기반의 데일리 트랙** — 내 Day 1, Day 2… 가 곧 입사 N일차
2. **시나리오 응대** — 단어 외우기가 아니라 "오늘 부장님이 보고서 양식 알려달라고 함" 같은 상황
3. **NPC 동료/상사** — 동기, 사수, 부장, 클라이언트 등 캐릭터와 대화
4. **직급 레벨업** — 수습 → 인턴 → 사원 → 대리 → 과장 → 차장/부장 → 임원
5. **달력 기반 전사 이벤트** — 진도와 무관하게 모두 같은 날 겪는 분기 워크샵, 송년회 등 (커뮤니티 감각 + 실시간감)

## 차별점 (vs. 일반 어휘 앱, vs. 유비챌)
- 어휘 앱: 단어를 외움 → 1일1비: **상황을 산다**
- 유비챌: 4주 코호트, 사람이 운영, 영어 발화 집중 → 1일1비: **무제한 셀프서브, 자동화, 회사 문화/롤플레잉 자체가 컨텐츠**
- 두 상품은 **서로 대체재가 아니라 보완재** (자세한 비교는 docs/vs-yubichal.md)

## 왜 구독인가
- 회사 생활은 끝이 없어. 한 번 입사하면 매일 매일 새로운 일이 일어남 — 컨셉 자체가 구독에 자연스러움
- 직급 레벨업 = 결제 동기가 게임 안에 내장됨 ("승진 면접 통과하면 인턴됨" 같은 결제 전환 트리거)
- LTV 최대화: 1회성보다 누적 매출이 큼

## 장기 비전 (4 시즌)

1. **시즌 1 — 개인 입사 시뮬 (Day 1 ~ Day 180)**
   - 수습 → 사원 → 선임 → 대리 → 과장 → 차장 → 부장 → 이사
   - **메인 코스 클라이맥스: Day 180 회장 만남**
2. **시즌 2 — 팀 협업 + NG+ 라운드 (Day 180 ~ Day 360)**
   - 5가지 길 선택: 다른 부서 / 외국 본사 / 이직 / 스타트업 / 멘토 모드
   - 후배 멘토링, 부서 운영, 채용 인터뷰
3. **시즌 3 — 부서 운영 + 외국 본사 (Day 360+)**
   - 임원 시뮬 (M&A, IR, 위기관리)
   - 외국 본사 발령 시즌 (영국·미국 톤 차이)
   - 매년 반복되는 회사 캘린더 + 시즌 한정 이벤트
4. **확장 — 자체 슬랙 (메인 비전)**
   - 1일1비 안에 유저끼리 메신저처럼 소통
   - 단톡방, 채널, 익명 동기 그룹

자세한 평생 컨텐츠 메커니즘은 `docs/retention-mechanics.md` 참고.
