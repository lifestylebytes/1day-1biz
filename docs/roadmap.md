## 🎯 7개월 매출 목표 (5월 → 12월)

**목표:** **2026년 12월 월 매출 1,000만원**

### 역산 시나리오 3가지

| 가격 책정 | 필요 활성 구독자 | 월별 신규 모집 (이탈 가정 시) |
|---|---|---|
| 월 2만원 | 500명 | 매월 80-100명 |
| 월 3만원 | 333명 | 매월 60-70명 |
| 월 5만원 (프리미엄+코호트 결합) | 200명 | 매월 40-50명 |

> **추천:** 월 3만원 단일 가격으로 시작, 6개월 후 프리미엄 5만원 티어 추가. 단일 가격이 의사결정 마찰 가장 낮음.

### 7개월 누적 매출 곡선 (단순 모델, 가격 3만원, retention 70% 가정)

| 월 | 신규 모집 | 누적 활성 | 월 매출 |
|---|---|---|---|
| 5월 (베타) | 20 | 20 | ₩0 (무료) |
| 6월 (베타→정식) | 30 | 35 | ₩105만 |
| 7월 | 50 | 75 | ₩225만 |
| 8월 | 70 | 120 | ₩360만 |
| 9월 | 90 | 175 | ₩525만 |
| 10월 | 110 | 240 | ₩720만 |
| 11월 | 130 | 305 | ₩915만 |
| **12월** | **150** | **350** | **₩1,050만** ✅ |

핵심 가정:
- 월 retention 70% (즉, 사용자 중 70%가 다음 달도 결제)
- 신규 모집은 매달 일정 비율 증가 (콘텐츠+유비챌 funnel+SNS)
- 가격 3만원

이 곡선이 깨지는 가장 큰 리스크:
1. **월 retention 50% 이하** → 1000만원 도달 불가능. 학습 효과 부족이 주범
2. **신규 모집 정체** → 마케팅 채널 다각화 필요
3. **가격 저항** → 베타 마지막에 결제 의향 조사 필수

### 단계별 매출 마일스톤

| Phase | 시기 | 매출 목표 |
|---|---|---|
| Phase 0 (1-2일 프로토) | 5월 1-3일 | 0 (배포 자체가 KPI) |
| Phase 1 (클로즈드 베타) | 5월 ↔ 6월 초 | 0 (무료 베타) |
| Phase 2 (정식 출시) | 6월 ↔ 7월 | 월 100-200만원 |
| Phase 3 (컨텐츠 확장) | 7월 ↔ 9월 | 월 300-600만원 |
| Phase 4 (스케일) | 10월 ↔ 11월 | 월 700-900만원 |
| **Goal** | **12월** | **월 1,000만원+** |

### 만약 12월에 못 도달한다면?

다음 진단 순서:
1. **Retention이 낮은가?** → 학습 과학 5원칙 점검, 컨텐츠 강화
2. **신규 모집이 적은가?** → 인스타·블로그·유비챌 funnel 강화
3. **결제 전환이 낮은가?** → 가격·결제 페이지 A/B 테스트
4. **이탈자 컴백이 안 되는가?** → 유버디 컴백 메시지, 알림 강화

각 진단마다 다음 분기 작업 우선순위 결정.

## Phase 1 — 클로즈드 베타 30일 (5월 3일 ↔ 6월 초)

**목표:** 진짜 학습이 일어나는지 측정.

### 모집
- 유버디 채널·인스타로 "베타 입사자 모집" 공지 (10-20명)
- 유비챌 졸업생 우선 초대
- 무료 베타. "정식 출시 시 우선 입사 + 첫 달 50% 할인" 약속.

### 측정
- D1, D7, D14, D30 retention
- 어디서 이탈하는지 (학습 단계? 시나리오? UI?)
- 단어 인출 정확도 (간단한 테스트 모듈)
- 피드백 정성 인터뷰 5명 진행

### 작은 개선만 — 큰 변경 X
- 시나리오 오타 수정
- 명백한 버그 픽스
- 큰 신기능은 X (기능 추가 욕망이 가장 큰 함정)

**Phase 1 성공 조건:**
- D7 retention 50%+
- D30 retention 30%+
- "정식 나오면 결제 의사 있다" 답변 50%+
- 단어 인출 정확도 D7 60%+

이 중 2개 이상 못 만족하면 컨셉 자체 재검토.

## Phase 2 — v1 (정식 출시 준비, 6월 ↔ 7월)

**목표:** 결제·로그인·진도 저장 붙여서 정식 상품으로.

### 작업
- Vite 마이그레이션 (Babel standalone → 정식 번들)
- TypeScript 도입 (기존 JSX 파일부터 점진 변환)
- Supabase 연결 (이메일·카카오 로그인 + 진도 DB)
- Toss Payments 정기결제 통합
- 가격 결정 (월 1.5만 / 2만 / 3만 — 베타 사용자 인터뷰 보고 결정)
- 학습 과학 5원칙 본격 강화:
  - P1 강제 생성 액션 모든 시나리오에 의무화
  - P3 노벨티 이벤트 30일 캘린더에 명시적 배치
  - P4 인터리빙: 한 세션에 3-4 카테고리 섞이는 방식으로 시나리오 큐 재설계
  - P5 맥락 단서 점진 페이드 시스템 도입

### 출시
- 인스타·유버디 채널 동시 송출
- 유비챌 졸업생 30% 할인 코드
- 보증금 결제자 우선 입사

**Phase 2 성공 조건:**
- 정식 결제 사용자 50명+
- 결제 후 7일 환불률 10% 이하
- D30 retention 30%+ (베타와 동일 또는 향상)
