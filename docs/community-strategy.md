# 1일1비 — 커뮤니티 / 멤버 가시성 전략

## 질문
**멤버 간 활동·가입을 서로 보이게 할까?**

## 답: 단계적으로, 익명·집계 우선

| Phase | 가시성 수준 |
|---|---|
| Phase 0–1 (베타) | **거의 안 보임 + 집계만** — "이번 주 47명이 함께 출근" 정도 |
| Phase 2 (정식 v1) | **익명 동기 그룹** — 같은 입사일 5명 자동 매칭, 익명 닉네임으로 진도 공유 |
| Phase 3 (확장) | **opt-in 프로필** — 본인이 "공개" 선택 시에만 다른 사람이 검색·확인 가능 |
| Phase 4+ | **자체 슬랙** — 단톡방, 메시지, 채널 (1일1비의 메인 비전) |

## 왜 이 순서인가

### 왜 처음엔 안 보이는 게 나은가
1. **느린 학습자 보호** — 리더보드 보이면 빠른 사람만 살아남고 느린 사람 이탈. 학습 retention의 적
2. **사회 비교 부작용** — "쟤는 벌써 대리네, 난 아직 수습…" 자존감 저하 → 환불 트리거
3. **개인정보 부담** — 가입할 때 "이 정보가 다른 사람에게 보이나?" 의심 = 가입 마찰
4. **콘텐츠 부족** — 커뮤니티는 컨텐츠가 핵심. 베타엔 컨텐츠 부족 → 빈 단톡방 = 죽은 느낌

### 왜 집계는 보여야 하나
1. **사회적 증명** — "47명이 함께" = 혼자 아니라는 안심감
2. **밴드웨곤 효과** — "다른 사람도 한다 = 가치 있다"는 신호 (학계 검증된 social proof)
3. **부담 없음** — 익명 집계는 누구도 노출 안 됨

### 왜 동기 그룹은 좋은가 (Phase 2부터)
1. **소속감** — 진짜 회사처럼 "동기"가 있다는 느낌 (몰입감 핵심)
2. **약한 사회적 압박** — "동기들 출근 중" 보이면 나도 출근하게 됨 (학습 과학 = mild peer pressure)
3. **5명 = sweet spot** — 너무 많으면 무시, 너무 적으면 죽음. 5명이 던바 친밀권의 코어
4. **익명** — 부담 줄이면서 사회 증명 받기

## 구체 디자인 (Phase 2 동기 그룹)

```
┌─ 사내 메모: "당신의 입사 동기" ─┐
│ 한도윤 · 마케팅 · Day 17 ✓    │
│ 임재희 · Product · Day 17 ✓   │
│ 김지원 · BD · Day 16 ⏳       │  ← 어제 멈춤
│ 박서연 · Ops · Day 17 ✓       │
│ (나) 홍길동 · 마케팅 · Day 17  │
└──────────────────────────────┘
```

핵심:
- **익명 닉네임 가능** (실명/닉 토글)
- **누가 누군지 진도만 보임, 메시지는 안 됨** (Phase 2엔 채팅 X — 단순함 유지)
- **이름은 한글 일반 이름 풀에서 자동 생성** (한도윤, 임재희 등 = 회사스러운 이름)

## 절대 안 하는 것 (장기까지)

- ❌ **공개 리더보드** — 학습 retention의 적. 빠른 사람만 살아남음
- ❌ **연속 출근 일수 공개 비교** — 한 번 끊긴 사용자는 영원히 비교 열등
- ❌ **자랑글 피드** — 인스타 같은 거. 1일1비는 학습 도구지 SNS 아님

## 외부 공유는 환영

- 직급 승진 시 "축하합니다 [이름]님, 사원이 되셨어요!" 카드 → 인스타 공유 가능 (인스타 스토리 사이즈 자동 생성)
- 결과 공유 = 신규 유입 채널 + 기존 사용자 마일스톤 자존감

## 예외: "유버디 검증" 발표

매월 검증 통과자를 운영자 뷰에서 익명으로 공지하는 것 OK. 유비챌 5기에서 이미 잘 동작하는 패턴.

## 결론
**커뮤니티는 v1의 핵심이 아니다.** 학습 효과 + retention이 핵심. 커뮤니티는 그걸 강화할 때만 추가.
