# 1일1비 — 검증 전략

## 현재 상황 (2026-05-01 기준)

- **유비챌 5기 운영 중** — 매 기수 30~40명 꾸준히 모객. 비즈니스 학습 시장에 명확한 니즈 있음 (검증 ✅)
- **유버디 브랜드 이미 형성** — 1일1비 출시 시점에 이미 잠재 고객 풀이 있음
- **1일1비는 아직 베타 전** — 프로토타입 HTML 3개 있음 (prototype.html, mobile.html, simulator.html)

## 검증 가설

| # | 가설 | 검증 방법 |
|---|---|---|
| H1 | 비즈니스 어휘를 게임처럼 배우려는 수요가 있다 | (이미 부분 검증) 유비챌 모객 = 학습 수요 검증. 단, 게임화 형태에 대한 수요는 별도 검증 필요 |
| H2 | 한 달 1.5–3만원 구독에 지불 의사가 있다 | 가격 테스트 (랜딩 3가지 가격대) |
| H3 | 사용자가 매일 5–10분 꾸준히 사용한다 | 베타 30일 retention 측정 |
| H4 | 직급 레벨업이 결제 전환을 만든다 | 30일차 결제 페이지 전환율 |
| H5 | NPC 시나리오 응대가 단순 어휘 카드보다 재밌다 | 베타 사용자 NPS + 정성 인터뷰 |

## 추천 순서

### 1단계: 유비챌 졸업생 인터뷰 (이번 주)
- 유비챌 5기 졸업자 5–10명에게 1:1 인터뷰
- 핵심 질문: 끝나고 어떤 갈증이 남는지, 일상 유지 도구 있다면 쓸 의향 있는지
- 1일1비 컨셉 노출은 마지막 5분에만 (선입견 방지)

### 2단계: 클로즈드 베타 (5월 중순–6월)
- 유비챌 졸업생 + 본인 인스타 팔로워 중 10명 모집
- 프로토타입(simulator.html)으로 30일 운영
- 매주 정성 피드백 + 사용 데이터 수집
- **목표:** retention 60%+ (Day 30까지 살아남는 비율)

### 3단계: 가격 검증 (6월 말)
- 랜딩 페이지 3개 만들고 (월 1.5만 / 2만 / 3만)
- 인스타 광고 소액으로 트래픽 보내서 결제 의향 클릭률 비교
- 보증금 형태 ("정식 출시 시 우선 입사 + 첫 달 50% 할인 — 1만원 보증금")
- **목표:** 1만원 보증금 결제 30명 = 정식 출시 GO

### 4단계: 정식 출시 (7월~)
- 보증금 결제자에게 우선 입사 안내
- 유비챌 졸업생 대상 30% 할인 코드
- 인스타 + 직장인 커뮤니티에 컨셉 컨텐츠 동시 송출

## 측정 지표

핵심 KPI:
- **D1, D7, D30 retention** (목표: 70 / 50 / 30%)
- **승진 면접 통과율** = 수습 → 인턴 전환율 = 두 번째 결제율 (목표: 40%+)
- **결제 후 7일 환불률** (목표: 10% 이하)
- **NPS** (목표: 30+)

## 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 유비챌과 카니발리제이션 | docs/vs-yubichal.md의 포지셔닝 매트릭스 — 다른 자아의 사용자 노린다고 명확히 |
| 게임화가 가벼워서 진지한 학습자 이탈 | 1일1비는 진지한 학습자 타겟이 아니라는 게 컨셉 자체. 진지한 학습자는 유비챌로 밀어주는 funnel |
| 자동화 비용 (NPC 대사, 시나리오 30+ 만들기) | 시즌별 출시 (수습 시즌 먼저, 인턴 시즌은 사용자 트래픽 보고) |
| 컨텐츠 베껴짐 | 베껴지는 건 단어/시나리오. 베끼지 못하는 건 유버디 브랜드 + 유비챌 funnel + retention 데이터 기반 개선 사이클 |
