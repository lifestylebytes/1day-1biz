# 회장 — 미지의 인물 (CEO Mystery)

> 1일1비 컴퍼니 최상위 인물. 얼굴·이름·위치 미공개. 이사(Day 180) 도달 시 공개.
> 사용자 retention의 long-term hook이자, 일상 속 작은 노벨티(P3)의 정기 공급원.

## 게임 디자인 의도

### 왜 미지로 두는가
- **장기 retention 동력** — "임원 되면 회장 만난다" = 1년+ 결제 유지 동기
- **노벨티(P3) 정기 공급** — 매주 한 번 회장 흔적 발견 = 작은 도파민 부스트, 학습 강화
- **내러티브(P2) 강화** — 시나리오에 미스테리 한 줄 박혀서 "오늘이 평범하지 않은 날" 느낌
- **추측·수집 메커니즘** — 사용자가 단서 모아서 추측 = 능동적 참여

### 왜 사장 말고 회장인가
- "사장님" = 보통 실제 운영. 회장 = CEO 위, 창립자급, 가끔 등장하는 존재
- 외국계 표현으로는 "Chair" 또는 "Chairman/Chairwoman"
- 한국 직장인한테 자연스러운 호칭 ("회장님이 그러는데…")
- 평소엔 운영 안 하고 가끔 등장 = 미스테리 자연스러움

### 상호작용 횟수
- 매주 1번 = 단서 발견 (책상 위 메모, NPC 언급, 사옥 흔적)
- 분기 1번 = 큰 사건 (자동 발사된 영상, 손글씨 편지)
- Day 180 (이사 도달) = **공개 모먼트** — 메인 코스 클라이맥스

## 캐릭터 설정 (작가 가이드 — 일관성 유지)

### 기본 사실 (사용자한텐 미공개)
- 호칭: **회장 (Chair)**
- 성별: 미공개 (정황만)
- 나이: 50대 추정
- 출신: 한국, 외국계에서 시작 → 본인 회사 창립
- 위치: 본사 어디에도 없음. 출장 중·해외 본사 등 핑계
- 옷 스타일: 후드티 + 청바지 (사진에 살짝)
- 취향: 클래식 LP, 강아지, 오래된 만년필, 손글씨

### 사용자가 받는 단서들 (아주 천천히)
1. 손글씨 — 항상 만년필. 같은 필체.
2. 사옥 1층 회장실 = 항상 잠겨있음
3. 다른 NPC들도 회장 잘 모름 ("나도 입사하고 두 번밖에 못 봤어")
4. 가끔 책상에 LP가 놓여있음 (왜?)
5. 사옥 옥상에 강아지 사진 한 장
6. 회장 방 창문에 가끔 후드티 실루엣
7. 분기 발표 영상은 음성 변조 + 얼굴 가림
8. 외국 본사? 한국 본사? — NPC들도 의견 갈림

### 성격 떡밥 (사용자 추측 fuel)
- **재밌음**: 가끔 사용자 책상에 농담 메모 ("월요일 어떻게 견디지? — 회장")
- **세심함**: 신입 30일째 손글씨로 "수습 통과 축하" 메모
- **무뚝뚝**: 분기 발표 영상에서 "이번 분기 잘했네. 끝." 한 줄
- **인간적**: 회장 책상에 강아지 사진 + 사진 옆에 "구름이 - 16살" 메모
- **신비주의**: 옥상 정원에 회장이 좋아한다는 식물만 있음

이 다섯 면을 균형 있게 노출. 어느 하나에 치우치면 평면적 캐릭터.

- 회장 단서를 사용자 진도에 따라 자동 노출

### 절대 안 하는 것
- ❌ 너무 자주 노출 → 미스테리 망가짐. 주 1회 max.
- ❌ 회장 정체 너무 일찍 힌트 → 절제. 70% 미스테리 유지
- ❌ 회장 = 운영자(너) 매핑 → 너는 "버디 (유버디)". 회장은 별개 캐릭터
- ❌ 회장 너무 진지 → 가끔 농담·인간미 필수

## "회장 = 운영자" 아닌 게 중요한 이유

너 = 유버디 = 버디 = 사용자가 매일 만나는 사람
회장 = 미지의 캐릭터 = 사용자가 동경하는 존재

이걸 한 사람으로 합치면:
- 너 자신을 신비주의로 포장 = 부담 + 비현실
- 매일 보는 친근한 사람 + 드물게 보는 권위자가 같은 사람 = 카페 사장이 회장 코스프레하는 느낌
- 절대 X

**버디(유버디)는 친근, 회장은 미지.** 두 캐릭터.
