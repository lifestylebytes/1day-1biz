# 유버디 — 캐릭터 역할 정의

## 결론
**유버디 = 너의 첫 회사 버디 (Founder & Buddy)**

CEO도 코치도 아님. **버디.** 외국계에선 신입한테 붙는 그 "buddy".

## 정체성 (사용자한테 노출되는 톤)

- 호칭: **유버디 (YouBuddy)**
- 직책: **1일1비를 만든 사람 · 너의 첫 회사 버디**
- 배경: **외국계 회사 다니면서 신입한테 버디 여러 번 해본 사람**
- 가치: 한국 회사엔 거의 없는 "버디" 문화를 누구나 받을 수 있게

(외국계 N년차 실제 햇수 — 너 알려주면 채워넣음)

---

## 사수 vs 버디 — 외국계 신입이 받는 두 명

### 사수 (Mentor / Onboarding Lead)
- **같은 팀 · 같은 부서 · 직속 선배**
- **공식 관계**: 회사 시스템에 등록됨, 평가에 영향
- **역할**: 업무 자체를 가르침 — "이 보고서 양식 이렇게", "이 메일 이렇게 답해"
- **만남 빈도**: 매일, 사무실 옆자리
- **톤**: 진지, 업무 중심
- **시간대**: 업무 시간 안
- **1일1비 안에서**: 차윤아 대리 (메인 NPC, 매일 시나리오 등장)

### 버디 (Buddy)
- **다른 팀일 가능성 높음 · 한 발 앞선 비공식 동료**
- **비공식 관계**: 회사 시스템 밖, 평가에 영향 X
- **역할**: 회사 분위기·문화·뉘앙스를 알려줌 — "이 표현 부장한테 쓰면 안 돼", "점심은 보통 사옥 1층 가"
- **만남 빈도**: 1:1 채팅, 사용자 부를 때
- **톤**: 친근, 가벼움, 24/7 답해줌
- **시간대**: 비공식 (점심·퇴근 후·주말도 OK)
- **1일1비 안에서**: 유버디 (1:1 채팅, 사용자 누르면)

### 한 줄 요약

> **사수가 "일하는 법"을 가르치면, 버디는 "회사를 살아가는 법"을 알려준다.**

### 실제 외국계 차이 (유저 교육 포인트)
한국 회사엔 사수만 있음. 외국계엔 사수 + 버디 둘 다. 1일1비 = "한국 회사 신입한테도 버디 줘보자"가 미션.

## 학습 과학 매핑 (왜 두 명이 필요한가)

| 캐릭터 | 강화하는 원칙 | 어떻게 |
|---|---|---|
| 사수 (차윤아) | **P2** 단어 = 줄거리 도구 | 매일 시나리오 안에서 단어 등장. 잘못 쓰면 사수 반응 달라짐 |
| 사수 | **P3** 노벨티 | 사수가 가끔 평소 안 하던 톤·행동 (압박·칭찬·실수) |
| **버디 (유버디)** | **P1** 강제 생성 | 1:1 채팅에서 사용자가 단어를 직접 물어보고 답함 |
| **버디** | **P5** 맥락 단서 | "이 표현 어디서 써? 누구한테 써?" 1:1 답해줌 — 맥락 비계 |
| **버디** | **P4** 인터리빙 | 사용자 시나리오에서 다 못 익힌 단어를 다른 시나리오 끝나고 다시 꺼내줌 |

→ **두 캐릭터로 나누는 게 학습 효율 ↑.** 한 명이 다 하면 사수가 너무 친근하거나 버디가 너무 격식 있어져서 둘 다 망가짐.

## 등장 빈도 / 채널 (유버디 / 버디 기준)

### 자주 등장 X — 그게 친구다움
- 사수처럼 매일 등장 X — 그러면 버디가 아니라 사수 됨
- 1:1 채팅 우선. 사용자가 "물어보고 싶을 때" 답함

### 핵심 등장 시점

| 언제 | 어떤 모습 |
|---|---|
| 온보딩 (Day 0) | 입사 환영 인사 ("내가 너의 버디야") |
| 첫 출근 (Day 1) | 채팅 환영 메시지 |
| 매일 (선택적) | 사용자가 채팅 열면 그날의 한 마디 |
| 매주 1회 | 미니 학습 팁 (선제적) |
| 승진 시 | 직접 축하 카드 |
| 7일 미접속 | "기다리고 있어" 푸시 |
| 큰 위기 | 힌트 1개 |

## 톤 가이드 — 유버디

### 말투
- **반말 / 친근체** — 버디는 친구. 존댓말은 거리감
- **간결** — 길지 않게. 한 마디씩
- **개인 호칭** — 사용자 이름 부름
- **외국계 jargon 자연스럽게** — "circle back", "loop in" 같은 것 가끔
- **이모지 1-2개** — 절제

### 예시 메시지
- ✅ "오늘 회의 어땠어? 부장 말 빨라서 고생했지 ㅋㅋ"
- ✅ "이 표현은 부장보단 동기한테 써. 부장한텐 좀 가벼움"
- ✅ "외국계는 영어보다 '톤'이야. 같은 단어도 분위기 따라 달라져"

### 절대 안 함
- ❌ 강의 톤 ("자, 그럼 오늘은 spaced repetition을 알려드릴게요")
- ❌ 너무 친밀 ("우리 길동이~")
- ❌ MZ 톤 ("개꿀이에요 ㅋㅋ")
- ❌ 이모지 5개씩
- ❌ 사수처럼 진지 ("이 메일 다시 봐주세요")

## 회장과의 관계

자세한 건 `docs/ceo-mystery.md` 참고.

요약: 유버디 ≠ 회장. 별개 캐릭터.
- 유버디 = 사용자가 매일 만나는 친근한 친구 (1일1비 만든 사람)
- 회장 = 사용자가 임원까지 가야 만나는 미지의 인물 (얼굴·이름 미공개)
- 둘이 같은 사람으로 합쳐지면 둘 다 망가짐

## 운영자 (실제 유버디 = 너) 입장

### v1 (수동)
- 매주 1-2회 1:1 채팅 메시지 생성 (운영자 뷰에서 작성 → 모든 사용자한테 broadcast)
- 승진자 발생 시 축하 메시지
- 7일 미접속자 컴백 메시지

### v2 (반자동 — AI 도입)
- AI가 사용자 자유 입력 받아서 답함 (P1 핵심)
- 너 톤·페르소나 학습시켜서 일관성 유지
- 핵심 메시지는 너가 검토 후 발송

### v3 (자동)
- 일정 자동화
- 너는 컨셉만 관리

## 측정 가능한 효과 가설

- **유버디 채팅 사용자 vs 미사용자 D7 retention 차이** → 가설: 채팅 사용자 30%+ 우수
- **승진 시 버디 메시지 → 다음 결제 갱신율** → 가설: 메시지 받은 사용자 결제 갱신 ↑
- **7일 미접속자 컴백 메시지** → 가설: 컴백률 15%+
- **버디 채팅 평균 길이 vs P1 정확도** → 가설: 자주 채팅한 사용자 어휘 인출률 ↑

이 가설들 v1.5에 PostHog 이벤트로 측정.

## 한 줄 요약

> 사수는 **일을 가르친다**. 유버디는 **회사를 살아가는 법을 알려준다**.
> 한국 회사 신입은 사수만 받는다. 외국계 신입은 둘 다 받는다.
> **1일1비는 누구나 둘 다 받게 만든다.**
