# 1일1비 — Retention 메커니즘 (평생 컨텐츠 설계)

> Day 180 = 메인 코스 클라이맥스. 그 이후가 진짜 retention의 영역.
> 모바일 시뮬게임 표준 메커니즘을 학습 컨셉 안에서 변형해서 박는다.

## 모바일 시뮬게임 retention 메커니즘 (실제 사례)

| 메커니즘 | 예시 | 효과 |
|---|---|---|
| NG+ (New Game Plus) | 심즈, Stardew Valley | endgame 후 다시 시작 → 평생 |
| 시즌 / 분기 이벤트 | 동물의 숲, 카카오게임 | 1년 사이클 매년 반복 |
| 컬렉션 시스템 | 포켓몬, 동물의 숲 | 무한 수집 |
| 라이브 옵스 | 캔디크러시, Supercell | 운영자 매주 컨텐츠 push |
| 멀티플레이어 / 친구 | 카카오게임 류 | 친구 진도 비교, 선물 |
| 일상 루틴 | 모든 모바일 게임 | 매일 출석 보상 |
| 메인 + 사이드 | 일반 RPG | 메인 끝나도 사이드퀘스트 |

## 1일1비 적용 — 7가지 메커니즘

### A. NG+ — 라운드 시스템 (가장 강력)

Day 180 회장 만남에서 5가지 길 선택:

| 선택지 | 컨텐츠 | 어휘 풀 |
|---|---|---|
| 다른 부서 재입사 | 같은 회사, 다른 부서 (마케팅 → BD), 새 사수 | 그 부서 어휘 |
| 외국 본사 발령 | 런던/뉴욕 본사 6개월 | 영국식 vs 미국식, 글로벌 어휘 |
| 이직 (다른 외국계) | 컨설팅·IT·금융 등 다른 산업 | 산업 특화 어휘 |
| 친구네 스타트업 | 작은 팀에서 멀티 역할 | 스타트업 어휘 (fundraise, runway, equity, MVP) |
| 멘토 모드 | 신입 후배 받음, 가르치며 본인 복습 | 기존 어휘 깊이 강화 |

→ **5개 길 × 6개월 = 30개월 자연스럽게.** 매번 같은 회사 다닌다는 시즌 1 컨셉도 유지.

### B. 시즌 이벤트 (매년 반복되는 회사 캘린더)

`docs/notices-events.md`의 12개월 캘린더가 매년 반복. 캐릭터는 그대로, 사건은 다름:
- 1월 시무식 → 매년 다른 비전 발표
- 4월 워크샵 → 매년 다른 장소·테마
- 12월 송년회 → 매년 다른 회식 시나리오
- 매 시즌 한정 NPC 등장 (ex. 봄 인턴, 여름 외국 클라이언트)

→ **"매일 회사 가는 직장인" 컨셉 = 평생 자연스러움**

### C. 컬렉션 시스템 — 덕질 후크

| 컬렉션 | 채워질 때 사용자가 받는 것 |
|---|---|
| **단어 도감** | 부서별 마스터 칭호 ("마케팅 부서 어휘 마스터") |
| **NPC 도감** | 외국계에서 만날 수 있는 50명 칭호 |
| **시나리오 도감** | "이 시나리오 다 봤어요" 진행률 |
| **회장 단서 컬렉션** | 50개 (Day 180 reveal 후에도 계속) |
| **수료증** | 부서별·라운드별 마스터 증명서 (인스타 공유 가능) |

### D. 일상 루틴 (매일 5-10분)

- 매일 출근 = 한 마디 (출석)
- 매일 점심 = 작은 시나리오 1개
- 가끔 회식 (월 1-2회)
- 매주 1회 사수 톡, 매주 1회 버디 톡

→ 끝없는 일상이지만 매일 작은 차이 (P3 노벨티)

### E. 멘토 모드 — 학습 효과 폭발 (1일1비만의 차별점)

2라운드부터 가능. **신입 후배가 너한테 질문 → 너가 답변.**

학습 과학적으로 가장 강한 학습 = **가르치는 것 (Protégé Effect)**. 이게 일반 어휘 앱은 절대 못 함.

구현:
- 후배 NPC가 너한테 어휘 의미 / 사용법 / 적절한 톤 물음
- 너가 답하면 시스템이 정합성 검증 (P1 강제 생성 + 가르침 결합)
- 잘 답하면 후배 친밀도 ↑, 못 답하면 후배가 다시 물음

### F. 친구·동기 시스템 (Phase 2 이후)

- 같은 입사일 동기 5명 (익명, 진도만 공유)
- 동기가 부서 이동 / 승진 / 퇴사 같은 사회적 이벤트 보임
- "동기 한도윤이 BD로 이동" → 너도 자극받음

자세한 가시성 정책은 `docs/community-strategy.md`.

### G. 라이브 옵스 (운영자 = 너)

- 매주 운영자 뷰에서 1-2개 공지 push
- 매월 CEO Talk (= 버디 톡)
- 분기마다 큰 이벤트 (M&A 시뮬, IPO, 글로벌 컨퍼런스)
- 사용자 피드백 받아서 다음 시즌 컨텐츠 조정

## LTV 추정

가정:
- Day 180까지 retention 70%
- 그 후 retention 50%
- 가격 월 3만원

평균 LTV = 9-12개월 = **30만원 / 사용자**
350명 × 30만 = **연 1억 LTV** 가능

## 핵심 가설 (검증해야 함)

| 가설 | 측정 |
|---|---|
| Day 180 회장 reveal이 결제 갱신율을 높인다 | Day 175 결제율 vs Day 180 retention |
| 라운드 선택이 LTV를 늘린다 | 1라운드 종료자 vs 2라운드 진입자 30일 후 retention |
| 멘토 모드가 어휘 정확도를 높인다 | 멘토 모드 사용자 D7/D30 단어 인출률 |
| 컬렉션이 일일 활동 횟수를 늘린다 | 컬렉션 인터랙션 빈도 vs DAU |

A/B 테스트 인프라 갖춰지면 가장 먼저 측정.

## 적용 시점 (Phase 매핑)

| Phase | 적용 메커니즘 |
|---|---|
| Phase 0-1 (베타) | 일상 루틴 + 시즌 이벤트 (수동) |
| Phase 2 (v1) | + 컬렉션 시스템 |
| Phase 3 (v2) | + NG+ 라운드 시스템 + 멘토 모드 |
| Phase 4 (v3) | + 친구·동기 시스템 + 라이브 옵스 자동화 |

핵심: **메인 코스 안 살아남으면 NG+ 안 만든다.** Day 180 retention 30% 이상 검증된 후 NG+ 만든다.

## 절대 안 하는 것

- ❌ Pay-to-win — 1일1비는 학습 도구, 게임 아님
- ❌ 가챠 — 사용자 돈 빼먹는 메커니즘 X
- ❌ 무한 도파민 루프 (스크롤·뽑기) — 학습 retention과 충돌
- ❌ 사회 비교 leaderboard — 느린 학습자 이탈

→ 1일1비의 retention은 **학습 가치 + 캐릭터 애착**으로 끌어가야 함. 게임 dark pattern 차용 X.
