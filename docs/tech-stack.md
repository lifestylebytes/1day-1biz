## v1 (웹 베타) 결정 — 이게 지금 우리가 만들 것

| 영역 | 선택 | 이유 |
|---|---|---|
| 시작점 | **현재 simulator.html 그대로 사용** | 인라인 React + Babel. 즉시 동작. 1-2일에 띄울 수 있는 유일한 옵션 |
| 호스팅 | **Vercel (또는 Netlify)** | GitHub 연결하면 푸시할 때마다 자동 배포. 무료 티어 충분 |
| 도메인 | `1ilbi.com` 또는 `youbuddy.co.kr/1ilbi` 같은 서브패스 | 신뢰도 + 유버디 브랜드 묶기 |
| 분석 | **PostHog 무료** | 펀널·리텐션 기본 제공. 인스톨 5분. 1일1비의 P1~P5 가설 측정용 |
| 에러 | **Sentry 무료** | 사용자 에러 자동 수집. 솔로 운영에 필수 |
| 결제 | (없음 — v1은 무료/베타) | 결제는 v2에서 |
| 인증 | (없음 — localStorage로 로컬 저장만) | 진도가 기기에 묶이지만 v1엔 충분 |
| 피드백 | **Tally.so 또는 Google Form** + KakaoTalk 채널 | 5분 만에 구축 |

→ **v1 출시까지 새로 배워야 할 기술: 0개.** Vercel 계정 만들고 Git push만 알면 됨.

## "지금부터 안 어기면 v2 갈 때 안 빡센" 원칙 (지금 단계는 가볍게만)

이 원칙들은 v1.5에서 본격 적용. v1 시점엔 인지만 하고 있으면 됨.

### 원칙 1. 데이터와 UI 분리 (v1.5에서)
지금 `window.WORDS`, `window.__SIM` 같은 글로벌 변수 OK. v1.5에 정리.

### 원칙 2. 웹 전용 API 비즈니스 로직에서 직접 호출 안 하기
- ❌ `localStorage.getItem('day')`을 컴포넌트 안에서 직접 호출
- ✅ `storage.get('day')` 처럼 한 번 감싼 함수로 호출
- v1엔 어차피 localStorage만 쓸 거지만, 함수로 감싸두면 v2에서 Capacitor Preferences로 바꿀 때 한 줄.

### 원칙 3. 디자인 토큰 한 곳에 (v1에 이미 있음 — sim/styles.css의 :root)
- 이미 `--paper`, `--ink` 같은 CSS 변수로 잘 돼있음. 유지만 잘 하면 됨.

### 원칙 4. 환경변수로 환경 분리 (v1.5에서)
v1엔 그냥 한 환경. v1.5부터 dev / production 분리.
