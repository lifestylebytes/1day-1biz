# 카카오 알림톡 템플릿 (솔라피 등록용)

2026-09-05 반려(UKAhr5fzRn) 사유 반영판. 반려 요지: (1) 수신자의 어떤 액션으로 발송되는지 문구에 없음, (2) 1회성인지 다발성인지 불명확. 다발성이면 "고객이 요청해서 매일 1회 발송된다"는 고정 문구 필요.

변수명은 kakao-daily/index.ts 와 정확히 같아야 한다. 버튼: 웹링크 "출근하기" → https://1day-1biz.youbuddy.co.kr/mainboard.html

## A. safe (SOLAPI_TEMPLATE_STYLE=safe, 권장)

```
[1일1비] 오늘의 출근 알림

#{이름}님, 신청하신 오늘의 표현 학습 알림입니다.

▶ 오늘 상황: #{상황}
▶ 오늘 표현: #{표현}
▶ 열린 학습: Day #{day}
▶ 더 학습할 수 있는 날: #{밀린}일
▶ 연속 출근: #{연속}일

아래 [출근하기] 버튼을 눌러 오늘 학습을 시작하세요.

해당 메시지는 고객님께서 1일1비 앱의 사원증/인사 > 알림 설정에서 직접 신청하신 오늘의 표현 학습 알림으로, 신청하신 시각에 매일 1회 발송됩니다. 알림 설정에서 언제든 해제할 수 있습니다.
```

## 검수 의견 제출 답변 (그대로 붙여넣기)

```
1. 발송 상황: 수신자가 1일1비 서비스(유료 회원제 영어 학습)에 가입한 뒤, 앱 내 "사원증/인사 > 알림 설정"에서 본인 휴대폰 번호와 받고 싶은 시각을 직접 입력해 신청한 경우에만 발송됩니다. 신청하지 않은 회원에게는 발송되지 않습니다.
2. 발송 성격: 수신자의 신청에 따라 신청한 시각에 매일 1회 발송되는 다발성 정보성 메시지입니다(그날 학습할 표현과 진도 안내). 수신자는 같은 알림 설정에서 언제든 해제할 수 있으며, 해제 즉시 발송이 중단됩니다.
3. 요청하신 고정 문구를 템플릿 하단에 추가했습니다: "해당 메시지는 고객님께서 ... 직접 신청하신 오늘의 표현 학습 알림으로, 신청하신 시각에 매일 1회 발송됩니다. 알림 설정에서 언제든 해제할 수 있습니다."
```

## 등록 후 할 일
- 승인된 템플릿 ID → `supabase secrets set SOLAPI_TEMPLATE_ID=...`, 스타일 → `SOLAPI_TEMPLATE_STYLE=safe|story`
- `supabase functions deploy kakao-daily --no-verify-jwt`, Cron `0 * * * *`
- `?dry=1&email=본인` 으로 변수 채워지는지 먼저 확인
